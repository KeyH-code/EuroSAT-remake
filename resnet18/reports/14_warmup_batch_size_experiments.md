# 14：1e-4 warmup + cosine 与 batch size 对照

实验日期：2026-09-26

## 用户决策与执行范围

用户确认的本轮方向：

1. 增加 warmup 支持；对 1e-4 采用 warmup，后段采用余弦退火，峰值 1e-4，总计 40 epoch。
2. batch size 从 128 减半到 64，训练 20 epoch。
3. batch size 设为 128 的四分之三，即 96，训练 20 epoch。
4. weight decay 缩小、梯度裁剪、label smoothing 暂未加入本轮，留待后续单独讨论。

用户提出 batch size 调小后观察后半程 loss 的变化。为让 64 与 96 两组相互对照，本轮这两组共用峰值 lr=1e-4、1 epoch warmup、余弦退火至 0、总计 20 epoch；两组之间只改变 batch size。128 组使用 40 epoch 周期，因此不是与 20 epoch 两组严格同周期的 batch-size 单变量对照。

## warmup 实现与配置

- 新配置名：`linear_warmup_cosine`；现有固定学习率和 epoch 级 `cosine_annealing` 配置仍可用。
- warmup：1 epoch，按 batch 线性从 `1e-5`（峰值的 10%）升至 `1e-4`。第一个 optimizer update 使用 `1e-5`；warmup 用完后到达峰值。
- 余弦阶段：从 warmup 结束后按成功的 optimizer update 逐 batch 下降，40 epoch 组覆盖剩余 39 epoch；20 epoch 两组覆盖剩余 19 epoch；`eta_min=0`。
- 续训 checkpoint 保存 warmup/余弦的 step 进度、总轮数、warmup 步数、峰值 LR 等状态。GradScaler 跳过更新时不推进 batch scheduler。
- 编译检查：`python -m compileall -q cnn resnet18 eurosat_paths.py` 通过。三组完整训练均作为训练链路验证；全部 checkpoint 记录 0 次跳步。

## 统一实验设定

ImageNet-1K V1 预训练 ResNet18，可训练范围 `layer4+fc`；BatchNorm 使用预训练 running statistics；AdamW，weight decay 0.01，默认 betas；seed 20260920；FP16 autocast + GradScaler（init scale 1024）；224×224，ImageNet mean/std，无随机增强，`num_workers=0`。沿用固定 `data/my_split.csv`（SHA-256 `66730fa4…e54bf`）：train 18,900、val 4,050、test 4,050。训练只读取 train 和 val，模型选择只看 val，test 未用于调参。

环境：Windows，RTX 4060 Laptop 8 GiB，PyTorch 2.14.0+cu130，Torchvision 0.29.0+cu130。三组单卡串行。

## 事实记录

- 三组逐 epoch 训练时间合计 4092.18 秒（68 分 12 秒）；从第一组运行目录创建（21:25:58）到最后一组独立复评完成（22:38:08）的墙钟时间约 72 分 10 秒。
- batch 64 best val acc 为 0.980741（3972/4050），高于 98% 记录门槛 3 张；batch 96 与 batch 128/40 ep 组 best val acc 都为 0.978765（3964/4050）。
- batch 64 与 batch 96 都在第 1 epoch 结束时将 warmup 从 1e-5 提升到 1e-4；各 20 epoch 末 LR 为 0。
- batch 64 的最低 val loss 出现在 epoch 4（0.074848），best accuracy 出现在 epoch 12（val loss 0.087566）。batch 96 的最低 val loss 出现在 epoch 5（0.080756），best accuracy 出现在 epoch 13（val loss 0.097356）。
- batch 128/40 ep 的最低 val loss 出现在 epoch 8（0.076120），best accuracy 出现在 epoch 20（val loss 0.100233）；epoch 40 的 val loss 为 0.108228。
- 三组 train accuracy 均达到 1.000000；训练总记录时间分别按 metrics 汇总，不含独立评价时间。
